接入步骤

  1. 等待来源显示“配置可领取”，下载该来源的配置包，并在服务器上保存为 0600 权限。
  2. 在 Sub2API 仓库根目录运行 sudo deploy/install-ai-log-shipper.sh /私密路径/shipper.json。
  3. 按安装器输出的 source_id 配置 Sub2API，挂载共享 WAL，再进行蓝绿发布。
  4. 确认心跳、Kafka 测试、HDD 回放均成功，再检查真实业务请求。

轮换时领取新配置并重新运行安装器；确认新凭据对应的 HDD 探测通过后，再点击“确认轮换”。停用会拒绝写入，源端 WAL 会积压，历史日志保留。
